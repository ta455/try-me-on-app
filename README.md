# Try Me On App

Try Me On is a cultural fashion discovery app where users explore outfits through a scrollable feed, learn the meaning behind each style, and instantly try the look on through a filter-like virtual try-on experience.

## Live Demo

https://ta455.vercel.app/try-me-on-app/

## Features

- Scrollable outfit discovery feed
- Cultural outfit detail pages
- Search and filter by culture, occasion, and style
- Save favorite outfits
- User preference selection
- Simple recommendation system
- Browser-based virtual try-on prototype
- Outfit sharing feature
- Mobile-shaped app layout

## Tech Stack

- React
- Vite
- React Router
- JavaScript
- CSS
- localStorage
- GitHub Pages

## Main Screens

- Feed page: browse cultural outfits
- Outfit detail page: learn history, symbolism, and styling notes
- Try-on page: preview an outfit overlay using the camera
- Saved page: view saved outfits
- Preferences page: choose preferred cultures and styles

## Project Purpose

The goal of this project is to combine fashion, culture, education, and interactive technology. Instead of only showing clothing images, Try Me On helps users understand the cultural meaning behind traditional outfits and experiment with a filter-like try-on experience.

## Current MVP Limitations

- The try-on feature currently uses image overlays, not full body tracking.
- Outfit assets are sample images.
- Recommendations are rule-based, not machine learning yet.
- User data is stored locally in the browser.
